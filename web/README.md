# Demonstration

This is the React application a reader should walk through: sign in, inspect a plan, and ask a question.

Setup and demo logins are in the repository README. From this folder: `npm install && npm run dev`, then open http://localhost:5173. The API is the FastAPI service at the repository root (`uvicorn api.main:app --reload --port 8000`).

`frontend/` is an earlier Streamlit prototype. It is not this demonstration.
